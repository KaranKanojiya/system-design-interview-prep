System Design Canvases

Interactive, diagram-driven study sheets for the System Design repo. Start with the three Foundations (CAP, algorithms, estimation), then each of the 20 use cases gets its own set of canvases. Open any canvas in a browser or Cursor (Live Preview); the diagrams are clickable and the calculators are live.
